## Goal

Use DAZ only where the immutable real-data residual-gap report justifies it, prove matched real-only versus mixture value, run resilient unattended operations, maintain current model/assets, and measure optional near-perfect/headline outcomes honestly.

## Why this section exists

Forty-three unresolved items remain across 1k/10k targeted generation, real/synthetic mixtures, seven-day soak, disaster recovery, currency/rollback, and optional independent-real-accuracy/scale claims. These are separate from core completion and must not be overclaimed.

## Scope

- Admit DAZ scale only from exact residual-gap cells with matched real-only ablation design.
- Generate targeted 1,000-scene and immutable 10,000-scene corpora with coverage/cost/retry profiles.
- Train/evaluate matched 10/20/30% mixtures and source/style/asset ablations.
- Select mixture weights only from real-image evidence; prove DAZ-disable/model rollback.
- Finish scheduler, disk reservation, retention, dashboards, alerts, backup/restore, failure campaign, seven-day soak, and recurring activation.
- Run quarterly currency/license/runtime/asset audits and rollback rehearsals.
- Run the 20-unseen-image blinded headline and measure quality, zero-touch, routine touches, manual edits, confidence, and failure bounds.
- Evaluate near-perfect thresholds without treating them as core assumptions.

## Work packages

1. Freeze residual-gap admission and candidate-selection policy.
2. Generate 1k/10k corpora with immutable cards and exact gap-cell bindings.
3. Run matched real-only and mixture training/evaluation/ablation.
4. Complete operations and disaster-recovery drills, then seven-day soak and recurring schedule.
5. Run currency, transferred-asset, rollback, and unseen-image headline evidence.
6. Publish optional-profile go/no-go decisions separately from core.

## Section-level testing

- Synthetic-first, stale-gap, missing-real-baseline, concentration, near-duplicate, and mix-cap admission failures.
- Matched split/config/seed and real-primary hard-bucket comparison tests.
